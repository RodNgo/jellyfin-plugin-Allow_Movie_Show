# Jellyfin Plugin: Allow Movie Show

Jellyfin plugin to hide/show specific Movie or Series items per user, while keeping folder/library access unchanged.

This plugin is inspired by the project structure used in [jellyfin-plugin-TelegramNotifier](https://github.com/RodNgo/jellyfin-plugin-TelegramNotifier).

## What this plugin does

- Adds a plugin configuration page in Jellyfin admin dashboard.
- Lets admin choose a user, browse **Movies** and **Shows** in **paged lists** (10 items per page for large libraries), and tick items to hide.
- Shows **library / collection name** next to each title (and in the **Hidden items** section) where Jellyfin exposes a `CollectionFolder` or `UserView` parent.
- Keeps folder permissions as-is, then blocks selected items per user via Jellyfin tag policy (`BlockedTags`).
- Supports per-user hidden list (`HiddenItemIds` + `HiddenItems` metadata) so each user can have a different visible catalog.
- Supports `Apply now` so rules can be applied immediately after Save without Jellyfin restart.

## Install plugin (developer mode)

1. Build the plugin:

```bash
dotnet build
```

2. Copy generated DLL to your Jellyfin plugins directory in this folder layout:

```text
plugins/
  AllowMovieShow/
    Jellyfin.Plugin.AllowMovieShow.dll
```

3. Restart Jellyfin server.

## Configure in Jellyfin

1. Open `Dashboard -> Plugins -> Allow Movie Show`.
2. Enable plugin.
3. Select a user.
4. Use **Previous page / Next page** under Movies and Shows to browse; tick items to hide. Use **Hidden items** to tick items you want to show again.
5. Save (plugin will auto-call `Apply now`).
6. Optional: click `Apply now` manually if you want to re-apply immediately.

## Notes

- This plugin is item-level visibility, not folder-level.
- Hidden logic is based on per-user blocked tags generated by this plugin.

## Release & publish on Jellyfin repository

### A) Build release artifact

```bash
dotnet publish Jellyfin.Plugin.AllowMovieShow/Jellyfin.Plugin.AllowMovieShow.csproj -c Release -o ./dist
```

Expected DLL:
- `dist/Jellyfin.Plugin.AllowMovieShow.dll`

### B) Create GitHub release

1. Commit and push code to GitHub.
2. Create tag (example `v1.0.1.0`) and push:

```bash
git tag v1.0.1.0
git push origin v1.0.1.0
```

3. Create release on GitHub and upload `Jellyfin.Plugin.AllowMovieShow.dll` as asset.

### C) Update `manifest.json`

In repo root `manifest.json`, add/update new version entry:
- `version`: your plugin version
- `targetAbi`: Jellyfin ABI compatible version
- `sourceUrl`: your GitHub repository URL
- `checksum`: SHA256 of uploaded DLL
- `timestamp`: release UTC time

You can compute SHA256:

```bash
shasum -a 256 dist/Jellyfin.Plugin.AllowMovieShow.dll
```

### D) Host manifest for Jellyfin

Use raw URL of `manifest.json`, for example:

`https://raw.githubusercontent.com/<your-user>/<your-repo>/main/manifest.json`

### E) Add repository in Jellyfin

1. Dashboard -> Plugins -> Manage Repositories
2. Add new repository:
   - Name: `Allow Movie Show`
   - URL: raw manifest URL above
3. Back to Catalog/Available plugins, install plugin, restart Jellyfin once.

## Project structure

- `Jellyfin.Plugin.AllowMovieShow/Plugin.cs`: plugin metadata + web page registration.
- `Jellyfin.Plugin.AllowMovieShow/PluginEntryPoint.cs`: applies rules on server startup.
- `Jellyfin.Plugin.AllowMovieShow/Services/DashboardVisibilityService.cs`: user policy update logic.
- `Jellyfin.Plugin.AllowMovieShow/Configuration/Web/`: Jellyfin admin config UI.
